# ইসলামিয়া কলেজ অ্যাসাইনমেন্ট কভার জেনারেটর

ইসলামিয়া সরকারি কলেজ, সিরাজগঞ্জ — **বাংলা বিভাগের** শিক্ষার্থীদের জন্য অ্যাসাইনমেন্টের কভার পেজ তৈরি ও প্রিন্ট করার ওয়েব অ্যাপ।

কয়েকটি তথ্য বেছে নিলেই কলেজের নির্ধারিত ডিজাইনে একটি নিখুঁত **A4 পোর্ট্রেট পিডিএফ** তৈরি হয়। কোনো শিক্ষার্থীকে আর হাতে কভার পেজ পূরণ করতে হবে না।

**লাইভ ওয়েবসাইট:** https://atikulislam.me/islamia-college-assignment-cover-generator/

GitHub Pages-এর মূল ঠিকানা: https://atikulislamx.github.io/islamia-college-assignment-cover-generator/ (কাস্টম ডোমেইন সেটআপের কারণে এটি উপরের ঠিকানায় রিডাইরেক্ট হয় — দুটোই চলে)

### স্থায়ী তথ্য (ইনপুট নয়)

- কলেজের নাম: **ইসলামিয়া সরকারি কলেজ**
- অবস্থান: **সিরাজগঞ্জ**
- বিভাগ: **বাংলা বিভাগ**
- বর্ষ: **প্রথম বর্ষ**
- শিক্ষাবর্ষ: **২০২৫–২৬**

## কীভাবে ব্যবহার করবেন

1. লাইভ ওয়েবসাইটটি খুলুন (অথবা এই রিপোজিটরির `index.html` ব্রাউজারে খুললেও চলবে)।
2. **বিষয়**, **কোর্সের নাম** ও **কোর্স কোড** বেছে নিন।
3. **নির্দেশনায়** অংশে শিক্ষকের নাম বেছে নিন।
4. নিজের **পূর্ণ নাম** ও **রোল নম্বর** বাংলায় লিখুন এবং **জমা দেওয়ার তারিখ** ক্যালেন্ডার থেকে নিন।
5. **লাইভ প্রিভিউ** দেখে নিন — চূড়ান্ত কভার পেজ ঠিক এমনই হবে।
6. **পিডিএফ তৈরি ও প্রিন্ট** বাটনে ক্লিক করুন।
7. প্রিন্ট ডায়ালগে:
   - কাগজের মাপ: **A4 (২১০ × ২৯৭ মিলিমিটার)**
   - মার্জিন: **কোনোটিই নয় (None)**
   - রঙ: **ব্যাকগ্রাউন্ড গ্রাফিক্স চালু** রাখুন (বর্ডার ও লোগোর জন্য)
   - গন্তব্য: **সংরক্ষণ করুন (Save as PDF)** — অথবা সরাসরি প্রিন্ট।

> প্রিন্টের সময় শুধু কভার পেজটিই আসে — ফর্ম, হেডার ও বাকি ইন্টারফেস স্বয়ংক্রিয়ভাবে লুকানো থাকে, আউটপুট সবসময় এক পৃষ্ঠা।

## প্রযুক্তি

- HTML5, CSS3, Vanilla JavaScript — কোনো ফ্রেমওয়ার্ক নেই।
- বাংলা ফন্ট: **Noto Sans Bengali** (Google Fonts; ইন্টারনেট না থাকলে সিস্টেমের বাংলা ফন্ট ব্যবহার হয়)।
- পিডিএফ: ব্রাউজারের নিজস্ব Print-to-PDF — তাই বাংলা যুক্তাক্ষর, কার-ফলা ও সংখ্যা কখনো ভাঙে না বা কেটে যায় না।
- কোনো ব্যাকএন্ড, ডেটাবেস, লগইন বা API নেই — **শিক্ষার্থীর কোনো তথ্য কোনো সার্ভারে যায় না**, সবকিছু ব্রাউজারেই তৈরি হয়।
- GitHub Pages থেকে সরাসরি চলে — Source: `main` শাখার রুট ফোল্ডার (`/`)। Jekyll প্রসেসিং বন্ধ রাখতে রিপোতে `.nojekyll` ফাইল রয়েছে।

## তালিকা পরিবর্তন / নতুন তথ্য যোগ করা

কোনো কোড লিখতে হয় না — শুধু ডেটার তালিকা সম্পাদনা করুন:

- **নতুন বিষয়** → `js/courses.js` → `SUBJECTS` অ্যারেতে নতুন লাইন যোগ করুন।
- **নতুন কোর্স বা কোড** → `js/courses.js` → `COURSES` অ্যারেতে `{ id, code, name, en }` যোগ করুন (`code` ইংরেজি অঙ্কে রাখুন; কভারে স্বয়ংক্রিয়ভাবে বাংলায় দেখাবে)।
- **নতুন শিক্ষক** → `js/teachers.js` → `TEACHERS` অ্যারেতে `{ id, name, designation }` যোগ করুন।
- **শিক্ষাবর্ষ বদল (২০২৫–২৬ → ২০২৬–২৭)** → `js/courses.js` → `INSTITUTION.session`।

পরিবর্তনের পর রিপোতে push করলেই GitHub Pages-এর সাইট কয়েক মিনিটের মধ্যে হালনাগাদ হয়ে যাবে।

## লোগো বসানো / হালনাগাদ

বর্তমান লোগো ফাইলটি কলেজের অফিসিয়াল ক্রেস্টের প্রকাশ্যে পাওয়া সবচেয়ে ভালো সংস্করণ (১৫০×১৫০)। লোগো **কোনোভাবেই পুনরায় আঁকা, কাটা বা বিকৃত করা হয়নি**।

স্বচ্ছ/উচ্চ-রেজোলিউশন সংস্করণ পেলে (যেমন কলেজ থেকে পাওয়া ৬০০×৬০০ পিক্সেলের বেশি) শুধু ফাইলটি বদলে দিন:

```text
assets/college-logo.jpg      ← নিজের ফাইলটি এই নামে ও পথে বসিয়ে দিন
```

অথবা `index.html`-এর দুটি `<img src="assets/college-logo.jpg">` ঠিকানা নতুন ফাইলের নামে বদলে দিন। ছবির অনুপাত বৃত্তাকার/বর্গাকার হলে ডিজাইন অপরিবর্তিত থাকবে।

## পরীক্ষার তালিকা (Quality Assurance)

এই অ্যাপের লজিক ১৩৯টি অটোমেটেড চেক দিয়ে যাচাই করা হয়েছে (jsdom) — ৮টি কোর্স, নাম⇄কোড সিঙ্ক, ৪ জন শিক্ষক, বাংলা নাম/রোল/তারিখ রূপান্তর, লাইভ প্রিভিউ, প্রিন্ট কল এবং এক পৃষ্ঠার প্রিন্ট সেটআপ। স্থানীয়ভাবে চালিয়ে দেখতে:

```bash
git clone https://github.com/Atikulislamx/islamia-college-assignment-cover-generator.git
cd islamia-college-assignment-cover-generator
python3 -m http.server 8000
# ব্রাউজারে: http://localhost:8000
```
